Automatic selection

The launcher prefers rootless Podman with krun and KVM. If prerequisites are unavailable it reports them and attempts isolated Apptainer; a usable fallback still requires its own prerequisites.

Persistent state

OMP uses an appliance-owned home. Target-specific workspace and scratch directories keep simultaneous targets separate. Host OMP configuration is opt-in.

Authority

GitHub checks the credential and repository rules. A Review queue row or Factory result does not grant approval, merge, or deployment authority.
