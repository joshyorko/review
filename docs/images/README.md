# Historical visual credits

`logo.png` is an unused Bluefin-era Review mark retained as an attribution
record; it does not define the current Review + Luna Factory product identity
and is not used by the launcher or workbench.

The artwork was guided by Bluefin's [canonical Deinonychus
illustration](https://github.com/projectbluefin/documentation/blob/main/static/img/user-attachments/97324a75-e6c6-409e-b9ee-18f69d3715d0.png)
and the [Bluefin mascot](https://github.com/projectbluefin/common/blob/main/system_files/bluefin/usr/share/ublue-os/bluefin-logos/bluefin.png).
The [dinosaur guide](https://github.com/projectbluefin/documentation/blob/main/docs/dinosaurs.md)
credits the creature designs and drawings to **Jacob Schnurr**; the source
documentation is [Apache-2.0 licensed](https://github.com/projectbluefin/documentation/blob/main/LICENSE).
